# Featured Projects

## [DataVerse](https://data-verse-jayan.vercel.app/)
### Learning Platform & AI Roadmap Generator

A centralized learning platform serving as an interactive presentation repository, AI-powered career roadmap generator, and autonomous presentation generation engine — built entirely on flat-file storage with no external database.

### Highlights
- 4-Agent LangGraph pipeline (Researcher → Educator → Coder → Designer) that autonomously drafts, codes, and styles interactive HTML presentations from a single topic prompt
- AI-driven career roadmap wizard using LLM structured outputs to generate 5+ phase learning paths with tools, projects, and resources
- Client-side PDF export of the roadmap via `html2canvas` + `jsPDF`

### Tech Stack
`Next.js 15` • `React` • `LangChain` • `LangGraph` • `Gemini API` • `HTML5/CSS3`

### Links
- 🌐 Live Demo: https://data-verse-jayan.vercel.app/

## [AutoData](https://github.com/JayanGupta/AutoData)
### Local-First AI Data Analyst & Interactive Visualization Engine

A self-contained, open-source AI analytics pipeline that lets users upload raw datasets and instantly receive data profiling, dynamic visualizations, automated data cleaning, and natural-language insights directly on their local machine.

### Highlights
- Welcoming contributions and built for open-source scale
- Guided data-cleaning studio with fully undoable column operations
- Automatic data-quality scoring, semantic type inference, and PII detection
- Local rule-based analytical engine with an optional LLM interface for deeper Q&A

### Tech Stack
`FastAPI` • `React` • `Next.js` • `pandas` • `Tailwind CSS` • `SQLite`

### Links
- 🌐 Source Code & Docs: https://github.com/JayanGupta/AutoData
